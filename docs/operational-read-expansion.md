# Операционные данные MCP: первый пакет

Подготовлено 15.09.2026. Восемь дополнительных инструментов работают через
существующие RBAC, фиксированные API-хосты, read-only allowlist, ограничение
размера ответа и общую квоту продавца. Отчёт остатков
`wb_seller_warehouses_stock_report` входит в ту же ветку отдельным изменением.

| Инструмент | Контракт | Аргументы и назначение |
|---|---|---|
| `wb_fbs_new_orders` | GET `/api/v3/orders/new` | `account`; новые сборочные задания |
| `wb_fbs_orders` | GET `/api/v3/orders` | `account`, `date_from`, `date_to` (UTC Unix seconds), `limit` 1–1000, `next` от 0; одна страница |
| `wb_fbs_order_statuses` | POST `/api/v3/orders/status` | `account`, `orders`: 1–1000 уникальных положительных int64 ID |
| `wb_promotion_balance` | GET `/adv/v1/balance` | `account`; баланс, взаимозачёт, бонусы |
| `wb_promotion_budget` | GET `/adv/v1/budget` | `account`, `advert_id`; бюджет одной кампании |
| `wb_promotion_costs` | GET `/adv/v1/upd` | `account`, `from`, `to`: YYYY-MM-DD, до 31 календарного дня включительно |
| `wb_promotion_payments` | GET `/adv/v1/payments` | Те же даты; пополнения, отдельно от расходов |
| `ozon_api_key_roles` | POST `/v1/roles` | `store`; права текущего ключа, пустое тело запроса |

Это ограниченные live-чтения. Пакет не добавляет расписание или новые источники
в фоновый сборщик. Повторный вызов инструмента обращается к API с соблюдением
квот; результат сам по себе не становится опубликованным снимком PostgreSQL.

## Полнота и смысл данных

У `wb_fbs_orders` обязателен фиксированный период до 30 суток. Передавайте
одинаковые даты на всех страницах; сохраняйте `next_cursor` вместе с ними.
Метод WB содержит историю не старше трёх месяцев, без текущих статусов.
Непустая страница обязана продвигать курсор. Пустая страница возвращает
`page_is_last=true` и `next_cursor=null`; это окончание выбранного диапазона,
не подтверждение получения всех заказов за всё время. Короткая непустая
страница сама по себе не доказывает завершение. Дубли ID и некорректные
страницы приводят к ошибке без публикации ложной полноты.

Сохраняется `deliveryType`: endpoint семейства FBS нельзя использовать для
автоматического отнесения любой строки к FBS. Операционные задания не являются
финансовой реализацией. Отдельные методы DBS этим пакетом не подключаются.

`wb_fbs_order_statuses` возвращает `missing_order_ids` и
`complete_for_requested_ids`. Отсутствие статуса не означает отмену, продажу
или отсутствие самого заказа. Статусы WB сохраняются как строки, чтобы новый
статус не превращался в известный старый. Адреса и идентификаторы покупателей
проходят существующее удаление персональных полей. Текст остаётся недоверенными
данными.

Рекламные пополнения не складываются с расходами. Историю затрат нужно сверять
с рекламной статистикой, а не прибавлять к ней. Документированный HTTP 204
на `/adv/v1/payments` нормализуется в `[]`. Пустой/повреждённый HTTP 200 и 204
с других новых endpoint не подменяются успешной пустой историей.

`ozon_api_key_roles` описывает upstream-ключ только выбранного доступного
кабинета. Это не изменение ролей пользователей MCP и не доказательство
подписки, успешного вызова каждого перечисленного метода или полноты данных.

## Квоты и ошибки

Три метода FBS разделяют квоту продавца `marketplace_fbs_orders` и локальную
паузу 2 секунды. Это консервативнее официальных 300 запросов в минуту и
учитывает стоимость ответа 4XX как 10 запросов. Автоматический повтор отключён.

Истории затрат и пополнений имеют отдельные квоты `promotion_costs` и
`promotion_payments`, по часу каждая: безопасный режим для Base-токена,
пока более высокий тариф доступа не подтверждён. Нет ожидания часового слота
внутри MCP-вызова: возвращается cooldown. При 401/402/403/429/5xx нет
автоматического повтора. Остальные источники имеют собственные квоты.
Баланс и бюджет используют существующие внутренние методы клиента и их
координацию с рекламной автоматизацией.

## Проверенные источники

- [WB FBS: запросы, статусы, лимиты и период](https://dev.wildberries.cn/docs/openapi/orders-fbs)
- [WB Продвижение: баланс и финансовая история](https://dev.wildberries.cn/docs/openapi/promotion)
- [Официальное объявление Ozon о `/v1/roles`](https://t.me/s/OzonSellerAPI?after=491)
- Пользовательский `OFK_API_catalog_2026-09-15.json`: копия схемы `/v1/roles`,
  без параметров запроса, авторизация Client-Id/Api-Key. Текущий swagger Ozon
  при проверке недоступен; этот пакет не подтверждает live-доступ кабинетов.

Перед включением фонового сбора нужны самостоятельные checkpoint, дедупликация
заказов, возобновление периода и атомарная публикация каждого источника. Этот
пакет предоставляет API-адаптеры и MCP-контракты для такой интеграции.

реализацию; обновление runtime и доступ кабинетов проверяются при выпуске.
