# Текущие остатки и операционные отправления Ozon

Для «текущие остатки и движение за 14.10» время наблюдения запасов и период
отправлений различаются. Текущий статус отправления не восстанавливает его
статус на конец прошлого дня.

## Источники

`ofk_source_snapshot(source=seller_stocks)` относится только к Wildberries.
Для Ozon после миграции 055 `source=stocks` сохраняет nullable present_units,
reserved_units и sellable_units. Исторические/WB резервы остаются NULL.
Сбор сначала перечисляет SKU/схемы product/info/stocks, затем читает физические
склады с обязательным фильтром SKU. Без фильтра FBO-метод возвращал HTTP 400.

Если native FBS не возвращает reserved, сохраняется явный резерв и общий
остаток из каталога под `sku-fulfillment-v2:fbs`. Физические строки этого же
SKU/схемы не добавляются рядом во избежание двойного счёта. present-free_stock
не используется как резерв. Физическая доступность публикуется отдельно
в cluster_stocks. Ручной и периодический сбор используют этот же путь.
Отсутствующая строка схемы/склада — неизвестное значение, не ноль.

После миграции 056 независимый `source=posting_movement` хранит количества
FBO/FBS без отмен, отмены и текущие статусы по SKU. Границы period_start и
period_end берутся из задания без переименования UTC-суток в местные сутки.
Источник не заменяет Seller Analytics sales в KPI. Перезапуск продолжает
сохранённые нормализованные страницы; контакты покупателей не сохраняются.

В reporting-only использовать опубликованные снимки stocks, posting_movement
и cluster_stocks. Дополнительный сбор включается отдельно через
REPORT_COLLECTION_REPLENISHMENT_ENABLED=true после миграций 055/056.
Выключенное состояние не создаёт и не захватывает дополнительные задания.
В live-подключении ozon_posting_sales_fallback читает обе схемы и все страницы.

Операционные количества в отправлениях не равны доставленным продажам или
полному складскому обороту. Приходы, возвраты, списания и корректировки не
восстанавливаются из postings. SKU/артикулы связывать только по проверенному
идентификатору; не подставлять нулевое движение без доказанной полноты.

## Разовая проверка 15.10.2026

Кабинет mebelnaya_furniturnaya_kompaniya: 2148 товаров visibility=ALL,
3203 уникальные пары SKU/схема, 8 единиц явного резерва FBS.
Отправления 14.10 UTC: FBO 150 без отмен / 1 отменённая;
FBS 71 без отмен / 1 отменённая. 105 SKU, pagination complete=true.
Это наблюдения за указанное время, не постоянные характеристики магазина.
